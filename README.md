## Project Description
AutoVault is a Java-based backup management application. It allows users to schedule automatic backups, manage version history, and restore previous versions of their files. 

## Key Features
*   Automatic scheduled backups (Priority Queue).
*   Version history with retention (keeps newest 5 versions).
*   Change detection (Timestamp and SHA-256 Hash).
*   Logging and Quality Assurance (QA) testing window.

## How to Run the Application
1. Open the project in Apache NetBeans.
2. Set `ui.Main` as the main class.
3. Run the project (Press F6). Both the GUI and CLI will launch.
